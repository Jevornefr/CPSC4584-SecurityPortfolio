# Bases

## Challenge Overview

This challenge demonstrates how Base64 encoding can be recognized and decoded.

## Investigation

I examined the provided encoded string and identified it as Base64.

I then used a Linux command-line utility to decode the Base64 data into readable text.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- Base64

## What I Learned

I learned how to recognize Base64-encoded information and use command-line tools to decode it.

## Security Takeaway

Base64 is an encoding method, not encryption. Encoded information can often be easily recovered and should not be relied upon to protect sensitive data.
