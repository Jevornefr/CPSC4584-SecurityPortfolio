# Static Ain't Always Noise

## Challenge Overview

This challenge demonstrates how static analysis can be used to examine an executable file without running it.

## Investigation

I examined the provided file using Linux command-line tools.

I used the `strings` utility to extract readable text contained within the file and searched the resulting output for useful information.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- strings
- Static analysis

## What I Learned

I learned that useful information can sometimes be recovered from executable files without executing them.

## Security Takeaway

Static analysis is valuable because security analysts can inspect suspicious files and identify useful artifacts while reducing the risks associated with immediately executing unknown software.
