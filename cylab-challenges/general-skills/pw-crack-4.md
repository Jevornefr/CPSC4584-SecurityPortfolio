# PW Crack 4

## Challenge Overview

PW Crack 4 builds on password-analysis concepts by requiring investigation of a Python password-checking program.

## Investigation

I reviewed the provided Python source code to understand how the program validated passwords.

I identified the password-checking logic and used that information to determine the correct input rather than attempting random guesses.

## Tools Used

- CyLab Security Academy WebShell
- Python 3
- Linux command line
- Source code analysis

## What I Learned

I learned how reading program logic can help identify weaknesses in password-validation mechanisms.

## Security Takeaway

Authentication systems should be designed so that reviewing application code does not expose credentials or make passwords easy to determine.
