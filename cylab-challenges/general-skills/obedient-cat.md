# Obedient Cat

## Challenge Overview

Obedient Cat is a General Skills challenge that introduces basic Linux command-line file operations.

## Investigation

I downloaded and examined the file provided by the challenge.

Using the Linux command line, I displayed the contents of the file directly in the terminal and located the information needed to complete the challenge.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- cat

## What I Learned

I learned how the `cat` command can be used to quickly display the contents of a text file from the Linux terminal.

## Security Takeaway

Basic command-line skills are important for cybersecurity because analysts frequently need to inspect files, logs, scripts, and configuration data directly from a terminal.
