# Warm

## Challenge Overview

Warm is a General Skills challenge that introduces working with executable files from the Linux command line.

## Investigation

I examined the provided file and learned that I needed to give it executable permissions before running it.

I used the `chmod` command to modify the file permissions and then executed the program with its help option to determine how it worked.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- chmod
- File permissions

## What I Learned

I learned how Linux file permissions control whether a program can be executed. I also learned that checking a program's help information can provide useful information about how the program is intended to be used.

## Security Takeaway

Understanding Linux permissions is important in cybersecurity because incorrect permissions can allow unauthorized users to read, modify, or execute files.
