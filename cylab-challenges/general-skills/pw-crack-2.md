# PW Crack 2

## Challenge Overview

PW Crack 2 is a General Skills challenge that demonstrates how a password-checking program can be analyzed to determine the expected password.

## Investigation

I examined the provided Python source code instead of repeatedly guessing passwords.

By reviewing how the program checked the user's input, I was able to determine what information the program expected and successfully complete the challenge.

## Tools Used

- CyLab Security Academy WebShell
- Python 3
- Linux command line
- Source code analysis

## What I Learned

I learned that reviewing source code can reveal important information about how authentication logic works.

## Security Takeaway

Passwords and other sensitive authentication information should not be hard-coded or exposed through application source code.
