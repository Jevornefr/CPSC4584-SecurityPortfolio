# Python Wrangling

## Challenge Overview

Python Wrangling is a General Skills challenge that demonstrates how Python scripts and command-line arguments can be used to process files.

## Investigation

I examined the provided Python script to understand its available options and expected inputs.

I used the script from the Linux command line with the appropriate arguments and supporting files to process the encrypted data.

## Tools Used

- CyLab Security Academy WebShell
- Python 3
- Linux command line
- Source code analysis

## What I Learned

I learned how to examine a Python script and determine how it should be executed from the command line.

## Security Takeaway

Understanding scripts and command-line arguments is important in cybersecurity because analysts frequently use automation tools to examine, transform, and process security data.
