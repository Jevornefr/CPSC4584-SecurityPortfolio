# Convert Me

## Challenge Overview

This challenge focuses on converting numbers between different number systems.

## Investigation

I reviewed the number provided by the challenge and determined that I needed to convert it into another number system.

I used my understanding of binary and decimal representation to perform the conversion and provide the requested result.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- Binary and decimal conversion

## What I Learned

I learned how computers represent numbers using different number systems and practiced converting between decimal and binary.

## Security Takeaway

Understanding binary, decimal, and hexadecimal is important in cybersecurity because these number systems frequently appear in networking, memory analysis, permissions, cryptography, and digital forensics.
