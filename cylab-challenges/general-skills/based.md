# Based

## Challenge Overview

Based is a General Skills challenge involving the conversion of values between different number systems and character representations.

## Investigation

I connected to the challenge service and received values represented in different number systems.

I converted the provided values into the requested format and submitted the results to progress through the challenge.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- Number-system conversion
- Binary
- Decimal
- Hexadecimal

## What I Learned

I gained more experience converting between binary, decimal, hexadecimal, and readable character representations.

## Security Takeaway

Understanding different number systems is important in cybersecurity because binary and hexadecimal values frequently appear in networking, memory analysis, cryptography, file formats, and system logs.
