# First Grep

## Challenge Overview

First Grep is a General Skills challenge that demonstrates how to efficiently search a file using the Linux `grep` command.

## Investigation

I examined the provided file and determined that manually reading through all of its contents would be inefficient.

I used `grep` to search the file for the relevant text pattern and quickly locate the required information.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- grep

## What I Learned

I learned how to use `grep` to search through large amounts of text and return only matching information.

## Security Takeaway

Searching large datasets efficiently is an important SOC skill. Commands such as `grep` can help analysts locate indicators, errors, usernames, IP addresses, and other important information in logs.
