# Wave a Flag

## Challenge Overview

Wave a Flag is a General Skills challenge involving the execution of a Linux program and the use of command-line options.

## Investigation

I examined the provided executable and determined how to run it from the Linux terminal.

I then used the program's help option to display information about its available commands and determine how to complete the challenge.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- Linux executable permissions
- Command-line options

## What I Learned

I learned that command-line programs often provide built-in help information that explains their available options and expected usage.

## Security Takeaway

Understanding how to safely inspect and interact with command-line programs is an important skill when analyzing unfamiliar software.
