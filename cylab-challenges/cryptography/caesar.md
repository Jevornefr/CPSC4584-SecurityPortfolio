# Caesar

## Challenge Overview

This challenge introduces the Caesar cipher, a classical substitution cipher that shifts letters by a fixed number of positions.

## Investigation

I examined the provided ciphertext and recognized that it was encrypted using a Caesar-style letter shift.

I tested the possible shifts until the ciphertext produced readable plaintext.

## Tools Used

- CyLab Security Academy WebShell
- Caesar cipher analysis
- Linux command line

## What I Learned

I learned how Caesar ciphers shift letters through the alphabet and how reversing the correct shift can recover the original plaintext.

## Security Takeaway

Caesar ciphers provide very little security because there are only a small number of possible shifts, making them easy to brute-force.
