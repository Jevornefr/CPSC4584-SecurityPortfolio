# What's a Net Cat?

## Challenge Overview

This challenge introduces Netcat, a command-line networking utility used to communicate with remote systems over TCP or UDP connections.

## Investigation

I used the `nc` command with the hostname and port supplied by the challenge.

The connection allowed me to communicate with the remote challenge service and receive information directly through the terminal.

## Tools Used

- CyLab Security Academy WebShell
- Linux command line
- Netcat (`nc`)
- TCP/IP networking

## What I Learned

I learned how a hostname and port can be used to establish a network connection from the Linux command line.

## Security Takeaway

Netcat is useful for troubleshooting and security testing, but it can also be used to create network connections and transfer data. Analysts should understand and monitor unexpected network connections.
